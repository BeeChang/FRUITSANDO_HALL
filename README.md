# 후.산.홀

## 요구 환경
- Android Studio (AGP 8.9.0 호환 버전 권장)
- JDK 17
- Android SDK: compileSdk 35 / minSdk 28 / targetSdk 35

Firebase (Remote Config), Retrofit / OkHttp, Kotlinx Serialization, Coil, Lottie, Timber
